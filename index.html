彩紙屋是一個在瀏覽器裡直接運作的色紙繪圖工作室：挑一張白紙、給它燙上金邊或雷射邊，再用鉛筆、炭筆、水彩、螢光筆、原子筆或燙金筆作畫，和朋友在同一張紙上一起畫、一起聊，最後互相交換作品。

功能一覽

它到底能做什麼？

每一個功能都是直接用瀏覽器的 Canvas API 自己畫出來的，沒有用任何繪圖套件。

✨

燙金邊 / 燙雷射邊色紙

金屬漸層、流動高光與四芒星金箔碎屑；雷射邊像彩虹糖紙般全像反光，可以拖色相滑桿或讓它自動流動變色。

✏️

六種畫筆

石墨鉛筆（選炭黑加粗就是炭筆）、暈染積水的水彩、半透明螢光筆、滑順原子筆、會閃閃發亮的燙金筆，以及局部擦除的橡皮擦。

🎨

自選顏色

色票、系統調色盤或直接輸入色碼（#E8747C），並自動給出顏色名稱。筆寬與濃淡都能獨立調整。

👥

雙人房間

建立房間會拿到 6 位房間號，只有拿到號碼的人進得來，每間限 2 人。筆跡、游標與紙邊設定即時同步。

🎁

交換色紙

把作品送給房間裡的夥伴，對方收下後從自己的畫廊挑一張回禮，雙方收到的作品都會存進「我的畫廊」。

🌗

深色 / 淺色模式

深色模式適合夜晚作畫，淺色模式像白天的文具店；第一次使用會跟隨系統設定，之後記住你的選擇。

    延伸資訊

    關於這個作品

    怎麼和朋友一起畫？
    在自己的電腦執行 node server.js，開啟 http://localhost:8787 ，建立雙人房間後把 6 位房間號或邀請連結傳給朋友即可。線上靜態版（GitHub Pages）沒有伺服器，所以無法聯機。
    我的畫會傳到哪裡？
    全部留在你自己的裝置與你所執行的伺服器上，不會上傳到任何第三方服務。
    要用什麼技術？
    純 HTML / CSS / JavaScript，繪圖使用 Canvas 2D API；後端是自己手寫的 WebSocket 伺服器，沒有使用任何第三方套件。
    怎麼回報問題或打分數？
    可以到 GitHub 專案（s20250088-coder/hi）提出 Issue；希望這些限制能在下一次更新中改善。
