# 彩紙屋 · 燙金 / 燙雷射 色紙彩繪

一個可以「選一張燙金色紙、用四種筆畫畫、和朋友聯機一起畫、聊天室聊天、交換色紙」的小網站。
只用 Node.js 原生的 `http` 模組與手寫的 WebSocket 實作，**零第三方套件**。

```
color-paper/
├── index.html      # 畫面結構
├── styles.css      # 深色 / 淺色主題、版面
├── theme-init.js   # 在第一次繪製前套用深色 / 淺色，避免閃白
├── app.js          # 色紙渲染、四種畫筆、協作、聊天室、交換色紙、畫廊
├── server.js       # 靜態檔服務 + WebSocket 房間伺服器（持久化畫廊）
├── scripts/build-pages.mjs  # 產生 GitHub Pages 用的靜態版（dist/）
├── .github/workflows/deploy-pages.yml  # 合併到 main 時自動部署
└── test/e2e.mjs    # 多人協作的端對端測試（16 項）
```

## 啟動

```bash
cd color-paper
node server.js            # 預設 http://localhost:8787
node server.js --port 9090 --host 0.0.0.0
```

然後瀏覽器打開 <http://localhost:8787>。
同一個 Wi-Fi 的其他裝置（手機、平板）用你電腦的區網 IP 連進來，例如 `http://192.168.1.20:8787`。

> 需要 Node.js 18 以上（用到內建 `crypto.randomInt`、global `fetch` 只在測試用到）。

跑測試（伺服器要先啟動）：

```bash
node test/e2e.mjs http://127.0.0.1:8787
```

## GitHub Pages

網站：<https://s20250088-coder.github.io/hi/>

每次 push（含合併 PR）到 `main`，`.github/workflows/deploy-pages.yml` 會自動：
`node scripts/build-pages.mjs` → 上傳 `dist/` → 部署到 GitHub Pages。也可以在 **Actions → Deploy 彩紙屋 to GitHub Pages → Run workflow** 手動觸發。

### 重要：Pages 是靜態網站

GitHub Pages 只提供檔案、不能執行 Node，所以 Pages 版**沒有聯機、聊天室與交換色紙**
（按鈕會清楚說明原因），但選紙、四種畫筆、紙邊、深色模式、存圖都正常。

想在 Pages 也能聯機，需要把 `server.js` 跑在一個支援 WebSocket 的雲端服務
（例如 Railway、Render、Fly.io），然後把網址指定成後端：

1. Repo → **Settings → Secrets and variables → Actions → Variables** → 新增 `PAGES_BACKEND`
   = `wss://你的網域`（或 `https://你的網域`）。
2. 重新執行部署，`dist/app.config.js` 會自動帶上這個位址，Pages 版的聯機就會連到它。

本機則不需要任何設定：直接開 `http://localhost:8787` 就有完整的聯機與交換色紙。

## 功能

### 色紙
- **20 種色紙底色**（櫻花粉、抹茶、夜藍、墨黑…），每張都有紙紋與纖維。
- **紙邊工藝**：
  - 素邊：手工壓凹紙邊
  - **燙金邊**：金屬漸層 + 流動高光 + 會閃爍的四芒星金箔碎屑
  - **燙雷射邊**：彩虹糖紙般的全像反光，可調整色相、按「▶ 流動」讓它慢慢變色，筆一移動反光就會跟著晃。
- 紙張尺寸：B4 / A5 / 方形 / B6 / 橫式 / 長條 / 卡片。
- 成品可以「存圖」下載成 PNG（左下角會烙上燙金落款）。

### 畫筆
| 筆 | 特色 |
|---|---|
| 鉛筆 | 石墨顆粒、紙紋、重壓處更深 |
| 水彩 | 水漬暈開、邊緣積水、斑點與不規則筆觸 |
| 螢光筆 | 半透明麥克筆，疊筆處加深 |
| 原子筆 | 滑順的實線、起筆墨點、紙上微微暈墨 |
| 橡皮擦 | 只擦得到，另外有復原 / 重做 / 清空 |

快捷鍵：`1` 鉛筆、`2` 水彩、`3` 螢光筆、`4` 原子筆、`5` 橡皮擦、`[` `]` 調整筆寬、`Ctrl/⌘ + Z` 復原。

### 聯機一起畫（雙人房間）
- 按「建立雙人房間」會拿到 **6 位房間號**（例如 `K3M7QF`），把房間號或邀請連結傳給朋友。
- 對方在「夥伴」分頁輸入房間號，或直接開邀請連結 `/?room=K3M7QF`，輸入暱稱即可進入。
- **只有拿到房間號的人才進得來，每間房間最多 2 人**，額外的人會被擋下並看到提示。
- 筆跡、紙張顏色與紙邊工藝即時同步；每個人在紙上有自己的彩色游標與暱稱。
- 重新整理頁面或斷線 60 秒內重連，會回到同一間房間（作品保留在伺服器上）。

### 聊天室
- 底部「聊天室」分頁，支援表情符號快捷鍵，沒在看聊天時會有未讀數量提示。
- 進入房間時會補上之前的聊天紀錄，加入 / 離開也會顯示系統訊息。

### 交換色紙
1. 在「夥伴」列表按某個人旁邊的 **🎁 交換**，送出你現在畫的這張色紙。
2. 對方會收到交換請求，可以先看預覽再決定「收下」或「婉拒」。
3. 收下後，對方從自己的「我的畫廊」挑一張回禮，點一下就送出。
4. 兩邊收到的色紙都會飛進**我的畫廊**（存伺服器，換裝置也在），可以點開下載。

### 深色模式
- 右上角「🌙 深色 / ☀️ 淺色」按鈕切換，會記在瀏覽器裡。
- 從沒選過時會跟隨系統設定（`prefers-color-scheme`）。

## 操作小技巧
- 按住 **Alt** 拖曳框選自己畫的筆跡，可以「✥ 搬移」或取消。
- 橡皮擦只擦得到筆跡，不會破壞色紙與紙邊。
- 網路斷線時你還是可以繼續畫，重新連上會自動補送。

## 資料與隱私
- 伺服器只在記憶體中保留房間；沒人的房間會自動清除。
- 交換收到的色紙存成 `data/gallery.json`（底圖 PNG），不會上傳到任何外部服務。
- 字型從 Google Fonts 載入，連不到時會退回系統中文字型。
